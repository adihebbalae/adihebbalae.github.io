PENTRIS

the real ECE 319H firmware, on its real board, on the bench where it was built

Adithya Hebbalae & Nevin Kuttarappallil

Firmware: Adithya Hebbalae & Nevin Kuttarappallil (2-person team). Game.cpp and Lab9HMain.cpp run here byte-identical to the flashed board, compiled to WebAssembly with only the peripheral layer replaced.

The PCB: the shared baseline board the ECE 319H cohort designed together at PCB camp (spring 2026); its silkscreen credits that team. Each student hand-populated and soldered their own copy. This one is Adi's build, not Adi's board design.

Board geometry: exported straight from the real KiCad file: 530 drill holes, real traces, real component positions. Display driver shims follow Valvano's ValvanoWare (Simplified BSD).

Honest gaps: the game loop is the real Lab9HMain / TIMG12 loop running under ASYNCIFY: menu, DAS, rotation, hard drop and game-over are all firmware behavior. Music streaming is still stubbed, so the speaker is silent and the scope's DAC trace is truthfully flat until the SD/FatFs milestone. Scope 2 has no probe, so it draws nothing. Browser timer clamping stretches the firmware's cosmetic pauses slightly.
